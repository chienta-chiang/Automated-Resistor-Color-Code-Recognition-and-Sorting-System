# Project history and sources

## Scope

This repository covers a **four-person undergraduate electrical engineering capstone** at Feng Chia University and the software refactoring that followed it. It contains the recognition code, the Arduino motor-control firmware, the ESP32-CAM firmware, the printable CAD parts, and the project's photographs, video excerpts and development figures.

## Development stages

| Stage | Scope |
| --- | --- |
| Undergraduate capstone (2024) | Color-code recognition logic, Arduino stepper-motor control, ESP32-CAM capture/upload firmware, and the three-tier sorting mechanism |
| Post-graduation refactoring | Modular Python vision/control workflow, mock and offline demonstration tools, HSV calibration utility, Python HTTP upload receiver, and 16 initial regression tests |
| Reliability work | Bounded FIFO capture queue and IDs, input/configuration validation, HTTP `2xx` response handling, and 31 additional reliability tests |

All post-graduation software work (refactoring, the Python receiver, tooling, and the 47-test suite) was developed with AI coding tools from task instructions I wrote (ChatGPT for planning, Codex for implementation) and reviewed by me. The capstone firmware and original recognition code are the team's 2024 work.

See [Contributions](../CONTRIBUTIONS.md) for individual and team responsibilities and [Validation](validation.md) for test coverage.

## Upload path

In the capstone demonstration, the ESP32-CAM posted each image to an XAMPP/PHP endpoint on the host PC (`C:/xampp/htdocs/upload/uploads/photo.jpg`). The Python host program watched that file, decoded the resistor and sent the result to the Arduino. During summer 2024 the team also ran a Python receiving server for camera tests.

The repository's [Python receiver](../src/vision/upload_server.py) serves the same multipart interface (`image` field, `photo.jpg`) and feeds a bounded capture queue. File-watching mode is still available as a legacy option.

[`original_run_evidence.png`](images/original_run_evidence.png) shows three moments from the capstone system:

- the host console detecting a new upload and sending the decoded value `12` to the Arduino;
- the ESP32-CAM serial monitor: Wi-Fi connection, upload, and `HTTP/1.1 200 OK`;
- a receiving-server log line for `POST /upload` returning `200` (31 July 2024).
